관리자 페이지

들어가기

관리자 페이지와 같은 GitHub 토큰으로 들어갑니다(한 번 들어가면 이 기기에 기억).

순서: ① 스타일과 가사를 복사해 Suno에서 노래를 만든다 → ② 고른 mp3를 여기서 올린다(다시 올리면 교체) → ③ 올리면 배포 작업이 가사 시간을 자동으로 맞춘다(몇 분) → ④ 어긋나면 '탭으로 맞추기'로 고친다. 노래는 Cloudflare R2(theway 버킷 psalms/)에서 스트리밍하고, 지금 노래가 무엇인지와 가사 시간은 저장소의 assets/psalms/<id>.json에 적힌다.

R2 열쇠

Cloudflare R2 → API 토큰(버킷 theway, 개체 읽기·쓰기)의 두 값. 이 기기에만 기억합니다.
